## Öğrenme ve uygulama görevleri

Roadmap etiketleri: `Actors`.

1. Ücretsiz Apache Pekko typed Java API ile izole report-job coordinator fixture'ı kur; actor identity/mailbox/message/protocol/lifecycle kavramlarını öğren.
2. Bounded mailbox, request/reply deadline, supervision ve retry budget uygula. Actor içinde mutable local state serialization ile distributed correctness garantisini ayır.
3. Duplicate/out-of-order input, actor crash/restart ve slow consumer testleri yap. Restart'ın volatile state'i koruduğunu varsayma; durable result için mevcut job owner contract'ını kullan.
4. Seçilmiş persistence/recovery lab'ı uygulanırsa journal/snapshot/replay ve serialization compatibility testleri ekle; yalnız dependency actor durability kanıtı değildir.
5. Actor sistemi canonical booking lock/transaction owner yerine geçmez; local lab cluster HA veya exactly-once delivery kanıtı değildir.
