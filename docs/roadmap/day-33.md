# Day 33 — Yerel serverless

Durum: **Planlandı**. Day bir milestone'dır; takvim günü sınırı yoktur.

## Önkoşul ve scope

[Day 32](day-32.md) kapanır; cumulative implementation branch'inden `day/33` türetilir. Bu gün başka datastore'ların sahipliğini devralmaz. Ortak kararlar [Project Decisions](../PROJECT-DECISIONS.md) belgesindedir.

## Görevler

1. Knative Serving üzerinde Java/Spring Cloud Function damage-summary function kur; request/invocation scale-to-zero ve cold-start ölç.
2. Requirement, alternatif, data/resource ownership, failure mode ve version compatibility kararını ADR'ye kaydet.
3. Mevcut dosya yapısında minimal gerçek use-case'i uygula; ihtiyaç yoksa aynı responsibility için ikinci ürün ekleme.
4. Idle→zero→request lifecycle, timeout ve auth negative test; HTTP lambda tek başına serverless sayılmaz.
5. Öğrenme notunu, runbook'u, ölçüm koşullarını ve karşılaştırma sonucunu güncelle.
