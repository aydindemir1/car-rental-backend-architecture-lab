## Öğrenme ve uygulama görevleri

1. Creating Core Components için mevcut Day 88 component API'ını genişlet; Avatar, Banner, Badge, Button, Card, Icon, Input Text ve Textarea gerçek React/TypeScript component'leri olsun.
2. Her component için props/variants/states, controlled/uncontrolled sınırı, semantic HTML, token use, error/loading/disabled behavior ve usage/do-don't guideline yaz; component adı tek başına uygulama değildir.
3. Avatar fallback/alt semantics; Banner critical alert vs status announcement; Badge color+text; Card heading/link structure için ayrı state story ve davranış testi oluştur.
4. Button type/submit/disabled/loading/double action contract'ını gerçek form üzerinde sınayarak backend idempotency'nin yerine UI disable koyma; Icon wrapper Day 135 registry'sini kullansın.
5. Input Text ve Textarea label/help/error/required association, unicode/length limit, validation timing ve form serialization davranışını test et; sadece placeholder label değildir.
6. Storybook local component catalog içinde normal/edge/error örneklerini göster; Vitest/Testing Library ve gerçek browser interaction testlerini ekle. Aşırı soyut 'universal component' oluşturma.
7. Mevcut portalın bir arama/inspection panelinde bu component'leri entegre et; keyboard/focus/zoom/light-dark davranışını doğrula, önceki API/state semantics'i koru.
