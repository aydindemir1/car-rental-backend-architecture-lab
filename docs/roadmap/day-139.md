## Öğrenme ve uygulama görevleri

1. Tooling/Development: Component Catalog ve Documentation için local Storybook/MDX kullan; props/state/usage/a11y/restrictions ve code links birlikte görülsün. Ücretli Chromatic zorunlu değildir.
2. Code Style, Unit Testing ve Accessibility Testing için mevcut ESLint/Prettier/Vitest/Playwright zincirini component package'a bağla; axe-core/Storybook a11y uygun sürümünü pin et.
3. Otomatik a11y testine kasıtlı missing-name/contrast fixture ekle; gate'i kırıp düzelt. Keyboard/focus/assistive-tech manuel smoke testleri de kaydedilsin; otomatik axe pass tam WCAG uyumu sertifikası değildir.
4. Deterministik local screenshot regression: viewport/browser/font/theme/animation koşullarını sabitle; gerçek beklenen değişime review/approve baseline süreci uygula. Blind baseline overwrite hatayı saklamasın.
5. Semantic Versioning ve Release Strategy: public component props/token semantics için breaking/additive/fix örnekleri; prerelease, changelog, deprecation window ve consumer upgrade fixture'ı uygula.
6. Local package artifact'ını mevcut CI ve local artifact dağıtımıyla version/pin et; build-once consumer fixture/deployment/revert behavior göster. Public npm/SaaS publish veya dış notification otomatik yapılmaz.
7. Commit Guidelines, PR Templates ve Contribution Guidelines: component change request→test→review rubric→release note→migration örneğini gerçek repo diff/fixture üzerinden tamamla.
8. Day 88'in Web Components artifact'ını React adapter contract ve SSR boundary testleriyle bağla; framework'e bağımlı package ve shared token kaynakları açık ayrılır.
