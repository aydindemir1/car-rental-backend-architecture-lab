## Öğrenme ve uygulama görevleri

Roadmap etiketleri: `Programming Languages`, `Java / Kotlin / Scala / Swift`, `Python`, `Ruby`, `Go`, `JavaScript / TypeScript`, `.NET Framework Based`, `Functional Programming`.

1. Java ana backend dili kalır; Python/Go ops Day 65 ve JS/TS frontend Day 81–82 implementation evidence'ını bağla. Bir dil seçimi bütün dilleri mandatory yeniden yazmak değildir.
2. Java'da immutable value transformation, pure function, higher-order mapping ve effect boundary'sini bir teklif fixture'ında uygula; business invariant'ı test et.
3. Seçilmiş ek JVM alternatif olarak Kotlin'de aynı bounded read/transform fixture'ını build/run et; Java interop/nullability ve exception contract'ını doğrula. Scala/Swift/Ruby dil seçenekleri gerekçeli Comparison olabilir.
4. İsteğe bağlı seçilmiş C#/.NET ücretsiz local CLI/read adapter profili ile aynı Java API'ını consume et; modern .NET ile klasik .NET Framework farkını açık yaz. Modern .NET kullanımı klasik Windows .NET Framework runtime uygulaması diye gösterilmez.
5. Language/runtime seçiminde ecosystem/operability/testing/interop/budget değerlendirmesini actual küçük program ve ölçümlerle yap; canonical datastore owner başka dile taşınmaz.
