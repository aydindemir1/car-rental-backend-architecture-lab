## Öğrenme ve uygulama görevleri

Roadmap etiketleri: `Web, Mobile`, `React, Vue, Angular`, `SPA, SSR, SSG`, `Microfrontends`, `W3C and WHATWG`, `Reactive Programming`.

1. Frontend Day 83/91–97 React/Vue/Angular ve SPA/SSR/SSG evidence'ını kullan; native Desktop/Mobile istisnası korunur. Mobile client konseptini API/latency/offline contract tasarımında değerlendir; native app implemented deme.
2. React shell + Vue veya Angular ayrı deploy/build microfrontend fixture'ı kur; route-based composition/custom element veya uyumlu module approach seç. Main portal tamamen rewrite edilmez.
3. Versioned interface, independent artifact/deploy, shared auth/design tokens ve mount/unmount boundary'yi uygula; bir remote outage/rollback diğer UI'yı çökertmesin.
4. Java Reactor/WebFlux için emlak Day 38 veya araç bounded stream fixture'ını real cancellation/backpressure/blocking-call testleriyle bağla; actor/reactive aynı yaklaşım değildir.
5. W3C/WHATWG için HTML/DOM/fetch/custom elements/a11y ilgili spec→uygulama→browser compatibility trace'i oluştur; yalnız standart adı tamamlanma sayılmaz.
6. Cross-origin/CSP/cache/version skew ve duplicate framework runtime etkisini ölç; iki microfrontend canonical business owner değildir.
