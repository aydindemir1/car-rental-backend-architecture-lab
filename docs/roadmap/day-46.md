# Day 46 — Recovery ve safety tatbikatı

Durum: **Planlandı**. Day bir milestone'dır; takvim günü sınırı yoktur.

## Önkoşul ve scope

[Day 45](day-45.md) kapanır; cumulative implementation branch'inden `day/46` türetilir. Bu gün başka datastore'ların sahipliğini devralmaz. Ortak kararlar [Project Decisions](../PROJECT-DECISIONS.md) belgesindedir.

## Görevler

1. Canonical MariaDB/graph state ile rebuildable Firebase/Solr/ClickHouse projection ayrımını backup/restore envanterine bağla; data lifecycle ölç.
2. Requirement, alternatif, data/resource ownership, failure mode ve version compatibility kararını ADR'ye kaydet.
3. Mevcut dosya yapısında minimal gerçek use-case'i uygula; ihtiyaç yoksa aynı responsibility için ikinci ürün ekleme.
4. Isolated real restore ve invariant verification; bir DB backup bütün stack verified recovery değildir.
5. Öğrenme notunu, runbook'u, ölçüm koşullarını ve karşılaştırma sonucunu güncelle.
