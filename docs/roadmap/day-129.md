## Öğrenme ve uygulama görevleri

1. DTOs, Usecases, Repositories, Mappers, Commands/Queries için Day 08/10/103 application/domain/transport sınırını gerçek code'e bağla. DTO dış contract'ı, mapper dönüşümü ve repository aggregate boundary'si aynı sorumluluk değildir.
2. Entities, Value Objects ve Domain Models için identity vs value equality, immutability, invariant, aggregate consistency ve domain language'i negative/regression testleriyle göster.
3. Transaction Script ile Domain Model'i aynı inspection task üzerinde ayrı profillerde çalıştır; basit CRUD vs invariant-rich behavior değişim maliyetini ölç. Transaction Script meşru bir pattern'dir, her koşulda hata değildir.
4. Identity Map: aynı EntityManager/persistence context'te aynı entity ID için aynı managed Java instance davranışını test et; context clear/ayrı transaction'da scope'u göster. Bu global Redis cache değildir.
5. ORMs: MariaDB/JPA/Hibernate gerçek DB ile dirty checking, flush, managed/detached entity, lazy loading, N+1 ve rollback senaryolarını çalıştır; SQL/output fixture kaydet.
6. Unit of Work ek öğrenme konusu olarak persistence context/transaction'da change tracking ve optimistic version conflict'i göster; DB transaction ile global distributed transaction aynı şey değildir.
7. Mapper/DTO'da mass assignment, lazy proxy leakage ve internal field exposure negative testleri; usecase authorization/idempotency ve command/query side effect sınırları korunur.
8. Identity Map'i framework sağlıyorsa mekanizmayı ikinci cache ile yeniden yazma; gerçek observability/test yeterlidir. Enterprise Patterns ana ve 11 alt düğümün hepsini code/contract/kanıta bağla.
