## Öğrenme ve uygulama görevleri

1. Carousel, List, Loading Indicator, Modal, Tabs, Toast ve Tooltip için gerçek component/story/test oluştur; mevcut navigation/status pattern'lerini reuse et.
2. Carousel için manual controls ve position label; autoplay varsa pause ve reduced-motion davranışı olsun. List semantics ve key/stable identity bir Card koleksiyonu ile test edilsin.
3. Loading Indicator'da busy state/announcement, bounded skeleton ve retry/error dönüşünü gerçek slow/failing API senaryosuna bağla.
4. Modal için initial focus, tab containment, Escape, focus return ve background interaction sınırını test et; native dialog uygunluğunu değerlendir. Nested overlay davranışını explicit sınırla.
5. Tabs için tablist/tab/tabpanel relationship, keyboard navigation ve activation mode; lazy/error state ile state restoration contract'ını kur.
6. Toast important/nonurgent live region ve dismiss/persistence; Tooltip focus/hover/dismiss, accessible description ve interactive-content sınırları testli olsun. Kritik hata yalnız kısa süreli toast/tooltip içinde kaybolmasın.
7. Day 133 microcopy ve Day 134/135 theme/icon/motion kurallarını tüket; reduced motion, zoom/keyboard/screen-reader ve empty/error state regression çalıştır.
8. Üç component grubundaki toplam 20 core component'in required state/test tablosunu tamamla; mevcut Verified component evidence'ını yeniden kullan.
