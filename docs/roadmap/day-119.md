## Öğrenme ve uygulama görevleri

1. Day 102 Java/Kotlin pure transformation örneğini yeniden kullan; aynı quote input/output contract'ını structured, functional ve OOP üç Java profiline uygula.
2. Structured Programming: sequence/selection/iteration ile açık control flow oluştur; validation, early exit ve resource cleanup senaryosunu yaz.
3. Functional Programming: immutable veri, composition, higher-order function ve referential transparency'yi uygula; effect'leri adapter sınırında tut.
4. Object Oriented Programming: davranışı kapsülleyen value/entity/policy collaborator'ları kullan; tek başına getter/setter içeren class OOP yetkinlik kanıtı değildir.
5. Random seed/clock/money rounding sınırlarını sabitle; empty/invalid input ve aynı fiyat invariant'ına üç profilde contract testi çalıştır.
6. Change request ekle: yeni ücret kuralı geldiğinde diff, duplication, test izolasyonu ve okunabilirlik trade-off'unu değerlendir. Paradigm'leri karıştırmanın meşru koşullarını yaz.
7. Java backend seçimini değiştirme; başka dil kurulumu bu gün için zorunlu değildir. Minimap ve ana Programming Paradigms düğümlerinin aynı evidence'ı paylaşmasını node ID bazında kaydet.
