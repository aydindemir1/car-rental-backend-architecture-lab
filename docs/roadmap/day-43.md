# Day 43 — AI streaming ve structured output

Durum: **Planlandı**. Day bir milestone'dır; takvim günü sınırı yoktur.

## Önkoşul ve scope

[Day 42](day-42.md) kapanır; cumulative implementation branch'inden `day/43` türetilir. Bu gün başka datastore'ların sahipliğini devralmaz. Ortak kararlar [Project Decisions](../PROJECT-DECISIONS.md) belgesindedir.

## Görevler

1. Spring AI model token streaming ve schema validated output kur; UI cancellation/backpressure/timeout ve invalid schema handling ekle.
2. Requirement, alternatif, data/resource ownership, failure mode ve version compatibility kararını ADR'ye kaydet.
3. Mevcut dosya yapısında minimal gerçek use-case'i uygula; ihtiyaç yoksa aynı responsibility için ikinci ürün ekleme.
4. Partial invalid output, disconnected client ve bounded output testleri; SSE genel öğrenme ile model streaming ayrı evidence.
5. Öğrenme notunu, runbook'u, ölçüm koşullarını ve karşılaştırma sonucunu güncelle.
