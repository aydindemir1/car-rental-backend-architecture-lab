## Öğrenme ve uygulama görevleri

Roadmap etiketleri: `Hadoop`.

1. Java ile Day 109 sahte dataset'ine MapReduce aggregate job'u yaz; resmi desteklenen ücretsiz Hadoop sürümünde local mode gerçek job çalıştır.
2. Kaynak bütçesi uygunsa separate local pseudo-distributed HDFS profili kur; namenode/datanode, block/replication ve input/output lifecycle'ını gözle. Local mode tek başına HDFS kullanımı değildir.
3. Malformed input, failed job/retry, output collision ve rerun idempotency testlerini yap; Spark sonucu ile aynı fixture aggregate'ını karşılaştır.
4. HDFS profilinde process outage/restart ve metadata/data backup sınırını test et. Tek host pseudo-distributed kurulum fiziksel HA/fault-domain kanıtı değildir.
5. MapReduce programming modeli ile Spark execution/recovery, shuffle ve storage rolünü ayır; canonical rental data HDFS'ye taşınmaz. Bütçe/uyumluluk engeli varsa HDFS distributed capability gap'i açık kalır.
