## Öğrenme ve uygulama görevleri

1. Input Checkbox, Input Radio, Input Switch, Select ve Dropdown component'lerini gerçek controlled state ve form adapter'ıyla uygula.
2. Checkbox tekli/grup/indeterminate, Radio group exclusivity/name, Switch on/off semantics için native HTML veya APG'a uygun contract kur; visual toggle görünümü rolün doğruluğunu tek başına kanıtlamaz.
3. Select seçim value'si için native baseline'ı koru; custom listbox gerekiyorsa selection/focus/typeahead/keyboard davranışını APG'a göre ayrı doğrula.
4. Dropdown action menu ile Select value seçimi farklıdır; menu/listbox/combobox rollerini ihtiyaçlarına göre ayır. Escape/outside click/focus return/open-close semantics açık olsun.
5. Required/disabled/readonly/invalid ve server validation error contract'ını form submit/serialize/reset ile test et; readonly desteklenmeyen native kontrol için explicit policy yaz.
6. Türkçe/uzun option text, zero option, unavailable value, async option failure ve hızlı duplicate action senaryolarını browser testine bağla.
7. Arama filtreleri veya teslim checklist'inde component'leri gerçek API/state akışına entegre et; UI permission hiding backend authorization'un yerine geçmez.
