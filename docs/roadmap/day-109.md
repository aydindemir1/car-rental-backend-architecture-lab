## Öğrenme ve uygulama görevleri

Roadmap etiketleri: `Working with Data`, `Hadoop, Spark, MapReduce`, `ETL, Datawarehouses`, `SQL Databases`, `NoSQL Databases`, `Apache Spark`, `Datawarehouse Principles`.

1. Mevcut SQL/NoSQL Day 10–11/19–22/37/57 ve ClickHouse analytics Day 21 görevlerini kullan; transactional canonical store ile derived warehouse/read model farklıdır.
2. Java Spark local mode ile sahte rental event dataset'ini temizle/normalize/deduplicate/aggregate et; seçilmiş DataFrame/SQL işlemlerini actual programda çalıştır.
3. Fact/dimension, grain, keys, slowly changing dimension ve late-arriving event örneğini küçük warehouse fixture'ında uygula; owner ve lineage belirt.
4. ETL extraction snapshot/version, schema evolution, checkpoint/restart/idempotent load ve rejected record yolu kur. Mevcut ClickHouse veya ayrılmış warehouse fixture derived hedef olsun.
5. Spark local execution ve data volume sınırını kaydet; distributed big-data/production scale kanıtı değildir. Hadoop/MapReduce aynı dataset karşılaştırması Day 110'da yapılır.
