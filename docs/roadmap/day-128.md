## Öğrenme ve uygulama görevleri

1. Microkernel: Java ServiceLoader ile inspection/report engine çekirdeği ve en az iki ayrı plugin JAR uygula; stable SPI ve version/capability contract'ı tanımla.
2. Plugin discovery/config/startup ve optional plugin yokluğu davranışını test et; compatible plugin değişiminde kernel source'unun değişmediğini artifact diff ile göster.
3. Broken/incompatible plugin, duplicate provider ve exception senaryolarında fail-fast veya izolasyon kararını uygula. ServiceLoader tek başına sandbox veya hot-unload mekanizması değildir; hot reload/untrusted plugin güvenliği iddia etme.
4. Blackboard: sentetik rental recommendation için shared candidate/working state, en az üç farklı knowledge source ve explicit control/scheduler oluştur. Price/availability/distance contributor'ları state'e stepwise katkı yapsın.
5. Termination/progress, priority, iteration/time budget, stale/conflicting suggestion ve contributor failure sözleşmesini test et. Basit event bus veya chain çalıştırmak Blackboard olarak adlandırılmaz.
6. Her iki pattern için farklı class/state/dependency diyagramı, plugin/knowledge source ownership ve sequence trace üret; birbirinin alternatifi olarak seçip birini atlama, roller farklıdır.
7. Recommendation yalnız öneri/read computation; Booking invariant owner'ı değildir. AI model gerekli değildir; deterministik fake candidate dataset yeterlidir.
