# Day 08 — REST, JSON ve OpenAPI

Durum: **Planlandı**. Day bir milestone'dır; takvim günü sınırı yoktur.

## Önkoşul ve scope

[Day 7](day-07.md) kapanır; cumulative implementation branch'inden `day/08` türetilir. Bu gün başka datastore'ların sahipliğini devralmaz. Ortak kararlar [Project Decisions](../PROJECT-DECISIONS.md) belgesindedir.

## Görevler

1. Resource tasarımı, validation, pagination, error response ve idempotency contract oluştur; canonical mutation sınırlarını yaz.
2. Requirement, alternatif, data/resource ownership, failure mode ve version compatibility kararını ADR'ye kaydet.
3. Mevcut dosya yapısında minimal gerçek use-case'i uygula; ihtiyaç yoksa aynı responsibility için ikinci ürün ekleme.
4. Invalid input, empty result, duplicate request ve dependency error contract testlerini çalıştır.
5. Öğrenme notunu, runbook'u, ölçüm koşullarını ve karşılaştırma sonucunu güncelle.
